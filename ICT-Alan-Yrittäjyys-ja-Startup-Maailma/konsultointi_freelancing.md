# IT-konsultointi ja kevytyrittäjyys

IT-konsultoinit tarkoittaa sitä, että yritys tai henkilö tarjoaa tietotekniikallista asiantuntija-apua toisille yrityksille.

IT-konsultti voi auttaa yrityksiä esimerkiksi: 

1. Tietotekniikasssa
2. Ohjelmoinnissa
3. Digitaalisissa palveluissa
4. Järjestelmissä
 
Kevytyrittäjyys tarkoittaa työn tekoa jota voi tehdä itsenäisesti ilman yrityksen perustamista.

Kevytyrittäjä voi tehdä:

1. Nettisivuja
2. IT-tukitöitä
3. Konsultointia
4. Ohjelmointia
