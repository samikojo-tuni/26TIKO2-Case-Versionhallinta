# Roblox engine

## What is Roblox

**Roblox** is a free online game platform and game creation system developed by Roblox Corporation. It allows users to program and play games created by themselves or other users. The platform has an avarage of 85.3 million daily users. Notable Roblox games include *Dress to Impress*, *99 Nights in the Forest* and *The Co-Worker Game* which was released by IKEA as an official virtual store that had real paid employees.

## Roblox studio

Roblox studio is the 3D creation suite.
You can create and cross-platform publish games through the
studio and even make money off of them. Roblox studio comes
bundled with the Roblox engine. Roblox studio includes pre-made templates that users can modify and use to create their own games.  In 2022 Roblox Corporation announced plans to incorporate AI to assist game creators in the process of using Roblox Studio. The plan was to allow Roblox users to generate games by writing prompts for the Roblox Studio AI. As of 2026, Roblox Studio features an AI assistant that can generate code for the user with a simple prompt. The generated results of Roblox Assistant can vary and official Roblox documentation encourages users to always check the results by playtesting.

### Roblox engine

Internally, parts of the engine were programmed in C++ but
mostly the engine and games made on Roblox use Luau as the
programming language. Luau is a programming language derived
from Lua 5.1 and was open sourced in 2021. Compared to Lua, Luau has added tools and custom optimizations written from scratch. As an optional component, Luau also implements native code generation.
