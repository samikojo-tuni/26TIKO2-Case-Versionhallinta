# Unity

## What is Unity and C#
**Unity** is the world's leading game engine built to create 2D, 3D and mobile games, primarily scripted using **C#**.

**Unity** can be used to create games for many different platforms, including phones, computers, websites and consoles such as Nintendo Switch, PlayStation and Xbox.

**C#** is a modern, object-oriented programming language developed by Microsoft. And it is widely used in video games, applications and web services. In Unity, **C#** is used to create game logic, control characters and objects, handle player input, and define how different elements of a game interact with one another.

## Notable features

**Unity** offers extensive tools for both 2D and 3D workflows, including dedicated rendering pipelines (such as URP for mobile and lightweight projects, and HDRP for high end projects) as well as a visual editor and component-based architecture.

**C#** provides clean syntax, rich libraries, async/event patterns, and editor scripting capabilities (such as custom inspectors and build pipelines) that help small indie teams iterate quickly and automate repetitive mobile tasks.

**Unity** also has an Asset Store where developers can find and purchase ready-made models, sounds, animations and other resources to help them build games more easily.
