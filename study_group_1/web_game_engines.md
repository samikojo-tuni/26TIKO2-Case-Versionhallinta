
# Web game engines (WebGL and WebGPU)


## WebGL

WebGL (Web Graphics Library) is an application programming interface (API) used to create 2D and 3D graphics within a web browser. WebGL is a product of Khronos Group, a US-based non-profit open standards organization. WebGL 2.0 is supported by all major browsers. WebGL uses JavaScript and runs in HTML5. WebGL is based on OpenGL and uses GLSL as the shading language.

## WebGPU

WebGPU is a graphics API that acts as an interface between JavaScript and GPUs. WebGPU is a newer, modernized version of WebGL with broader capabilities and is intended to eventually replace WebGL. WebGPU uses its own shading language WGSL (WebGPU Shading Language) and includes compute shaders. This enables heavy workloads that WebGL can't handle.

## Comparison And Advantages

WebGPU is an improvement on WebGL's core limitations like graphics and performance.
The problem with WebGPU is however that it's support is still narrow. As of late 2024, WebGPU is only available in Chrome and Edge as a stable feature while locked behind an experimental flag on Safari and Firefox.
To gain a wider audience, one must still use WebGL.
