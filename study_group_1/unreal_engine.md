# Unreal engine and C++ in AAA game production

## introduction

In this document we go over Unreal Engine and the usage of the C++ programming language in AAA video game productions.

### Unreal engine

Unreal engine is a game engine developed by epic games.

### monetization

Unreal engine is free for game developers, individuals and small businesses with revenue under $1 million USD and free for educators and schools with no revenue limit.

### features

- Pipeline integration
- World building
- Characters and animation
- Rendering, lighting, and materials
- Simulation and effects
- Gameplay and interactivity authoring
- Integrated media support
- Virtual production
- Content
- Developer tools
- Platform support

### History of Unreal engine

Unreal engine was developed by Epic Games. Originally it was made for a game in 1998 called Unreal. Initially it was made for (PC) first-person shooters but nowdays you can find it almost any type of game. Unreal engine is also used in film and television industry.

### C++ in Unreal engine

Unreal engine is written in C++ and that's why it is easily portable to different platforms like desktop, mobile, console and even VR. Unreal uses a lot of C++ macros to make coding more easy and accessible to new game makers.
In the future C++ will stay as a importat coding language in core engine systems but they have plans to start using "Verse" to make newer codes and games.

### Verse

Verse is a multi-paradigm programming language made by Epic games. Mostly used for "Fortnite" at the moment. Verse represents departure from typical programming language and makes way for new long-term programming.

Verse aims to be:

- Simple enough
- Expressive enough
- Safe enough
- Fast enough
- Stable enough
