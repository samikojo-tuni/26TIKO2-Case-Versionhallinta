# Green coding


## Definition

 It focuses on the environmental dimension of sustainability.
Sustainability software engineering considers three dimensions of sustainability, sosial, environmental and economic sustainability.

## Awareness

One or two watts (wh) saved for opitmizing a program run on the developer's mcachine might feel small, but can quickly saved up if the program is run by possibly thousands of users.
A survey made by Pang et.al. reveals, that software developers rarely think about the energy efficiency of the software, that they are developing. Only 18 precent of the respondents claimed to take energy consumption into account.
The research agrees that software practitioners have limited knowledge of developing more sustainability software.
Development machines usually are powerful hardware, compared to the user base's machines. A software developer might be oblivious of this extra power in their possession. This can lead to a situations where the application is not optimized at all for those lower powered machines. In worst scenario the user with a lower end machine cannot use the application and the application uses more energy than it would realle need. The option is for the user get more efficience machine.
The current situation can be compared to the times when computers had only little proceccins power and memory.
It was mandatory to write power efficient code for it to even work.
Developers feel that is not worth the effort to produce highly efficient code as more efficient hardware will ne available in the near future and will compensate for the inefficient code.
